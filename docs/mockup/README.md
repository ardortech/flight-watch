These are design-tool files, not app code. They won't render on their own in a browser (they need the design tool's runtime), but they are plain HTML with inline styles: read them for layout, copy, colors and behavior (the small script at the bottom of each file holds the sample data and interactions). All prices and flights in them are sample data.

To view them interactively, open the shared design canvas, or ask Claude (in the team account) to rebuild the canvas from this folder.
